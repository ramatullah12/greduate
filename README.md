# 🎓 Graduation Gift Website

A romantic and interactive web application created as a special graduation gift.

## ✨ Features

- 💌 Animated envelope opening
- ❤️ Personalized congratulatory letter
- 🖼️ Photo gallery
- 🎵 Background music
- ✨ Smooth page transitions
- 📱 Responsive design
- 🎀 Elegant romantic UI

## 🛠️ Built With

- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion

## 📷 Preview

A digital gift website designed to celebrate a special person's graduation with an elegant and memorable experience.
